Reading a rank

A 1,000 × 6 table of features has rank 5. What can you conclude?

Five of the 1,000 rows are independent, the rest repeat them
One column has missing values
One column is a combination of the others; a model cannot separate all six effects
The sixth column must be deleted
Why. Six columns but only five independent directions: some non-zero combination of columns is zero.

Answer C. Ask which column to drop: any one in the dependent combination; the choice is about meaning, not mathematics.

Block A · projection onto a line

The projection is the nearest point on the line, and the residual meets it at a right angle

p = (b · a / a · a) a

b = (2, 4), a = (3, 1): b · a = 10, a · a = 10, so p = (3, 1).

Residual b − p = (−1, 3), and (−1, 3) · (3, 1) = 0.

Why a right angle

If the residual leaned along the line, sliding the point that way would bring it closer. The nearest point leaves only the orthogonal part.

From slide_numbers.py, week 4. Draw b, the line, p and the residual. The coefficient b · a / a · a is the "shadow length" in units of a.

Onto a subspace

Onto the span of several columns, the projection matrix is A (AᵀA)⁻¹ Aᵀ

A with columns (1, 0, 1) and (0, 1, 1); v = (1, 2, 0)

P v = (0, 1, 1), residual (1, 1, −1)

The residual is orthogonal to both columns: (1, 1, −1) · (1, 0, 1) = 0 and · (0, 1, 1) = 0.

  • Condition: Aᵀ(v − P v) = 0, the normal equations
  • Compute it with a solve, never an inverse

From slide_numbers.py, week 4. Derive the formula from the orthogonality condition: Aᵀ(v − A c) = 0 gives AᵀA c = Aᵀ v. Week 5 meets the same equations as least squares.

Two properties

Projecting twice changes nothing, and a projection matrix is symmetric

P² = P

A point already on the subspace stays where it is.

Pᵀ = P

An orthogonal projection treats both sides alike. A projection that is not symmetric projects at a slant.

Use them as checks. If your P fails either, the code is wrong. The lab and the problem set test both.

Ask: what is P for a projection onto the whole space? The identity. Onto a single unit vector q? q qᵀ.

Where does the projection land?

Project b = (4, 2) onto the line through a = (1, 0). Which is the projection, and why?

(0, 2), the part along the second axis
(4, 0), since b · a / a · a = 4

(0.894, 0), the unit vector of b on the axis
Why. b · a = 4 and a · a = 1, so p = 4a = (4, 0); the residual (0, 2) is orthogonal to the line.

Answer B. Distinguish the coefficient (a number) from the projection (a vector) explicitly.

Block B · orthonormal bases

With an orthonormal basis, projecting is just dot products

  • Orthonormal: unit length, pairwise orthogonal: QᵀQ = I
  • Projection onto their span: P = Q Qᵀ, no solve needed
  • The coordinates of v are simply the dot products qᵢ · v
The plan. Turn any independent columns into orthonormal ones with the same span. That is Gram-Schmidt, and the bookkeeping is the QR factorisation.

Compare: A(AᵀA)⁻¹Aᵀ needs a solve; Q Qᵀ needs only products. QᵀQ = I is what makes the solve disappear.

Gram-Schmidt

Gram-Schmidt removes from each column what earlier columns already explain

Columns (3, 4) and (1, 0)Result
q₁ = (3, 4) / 5(0.6, 0.8)
Coefficient r₁₂ = q₁ · (1, 0)0.6
What is left: (1, 0) − 0.6 q₁(0.64, −0.48), length 0.8
q₂ = what is left / 0.8(0.8, −0.6)

From slide_numbers.py, week 4. Check q₁ · q₂ = 0.48 − 0.48 = 0 with the room. Each step is a week-4 projection: subtract the shadow on what you have, keep the rest.

The factorisation

A = Q R: Q holds the orthonormal columns, R the coefficients

For the example: R = [[5, 0.6], [0, 0.8]]

Column 1 of A = 5 q₁; column 2 = 0.6 q₁ + 0.8 q₂.

Q, R = np.linalg.qr(A)
np.allclose(Q.T @ Q, np.eye(2))   # True
np.allclose(Q @ R, A)             # True
Signs. A library may return −q and −r for some columns. Both are correct: QR is unique only up to those signs.

R is upper triangular because column j uses only q₁ to qⱼ. The library uses Householder reflections, not Gram-Schmidt: same Q and R up to signs, better rounding.

Checkpoint

Which check proves your QR is right?

Your function returns Q (5 × 3) and R (3 × 3) for a 5 × 3 matrix A. Which set of checks is enough?

QᵀQ = I
Q R = A
Q equals np.linalg.qr(A)[0] entry by entry
QᵀQ = I, Q R = A and R upper triangular
Why. Together they define a QR factorisation; each alone admits wrong answers.

Answer D. This is the property check the problem-set checker uses: it never needs your numbers to equal the library's.

Block C · rounding

When columns are nearly parallel, subtracting shadows leaves mostly rounding

  • Two columns at a tiny angle: almost all of the second is its shadow on the first
  • What is left is small, and rounding errors are a large part of it
  • Classical Gram-Schmidt projects the original column each time; modified projects the updated one, and keeps more accuracy
  • Libraries use Householder reflections, which keep Q orthonormal to rounding level

Do not give the lab's table now. Ask the room to predict which of the three loses orthogonality first as the columns become nearly parallel.

Why it matters

A Q that is not orthonormal gives wrong projections without any error message

Silent failure

Q Qᵀ v is a projection only if QᵀQ = I. Code that skips the check returns numbers that look fine.

The habit

After any factorisation, measure max |QᵀQ − I| and max |QR − A|. Both should be near 10⁻¹⁵ in float64.

Week 5 fits least squares through QR. Nearly collinear features are the data version of nearly parallel columns.

Checkpoint

A measured loss of orthogonality

For a QR of a feature matrix you measure max |QᵀQ − I| = 0.02. What is the soundest next step?

Suspect nearly dependent columns, check the condition number, and use a Householder QR
Accept it: 0.02 is a small number
Use fewer rows so the factorisation is faster and more accurate
Normalise each column of Q again to length 1
Why. A loss of 0.02 is about 10¹⁴ times rounding level: the columns are nearly dependent, and the method in use (typically classical Gram-Schmidt) does not keep Q orthonormal.

Answer A. Option D is a common reflex: it fixes lengths, not angles.

Week 4 · wrap-up

Three things to keep

Nearest means orthogonal

The residual of a projection is orthogonal to the subspace: Aᵀ(v − P v) = 0.

QR is projection bookkeeping

Q spans the same space with orthonormal columns; R records how to rebuild A.

Measure the loss

Check max |QᵀQ − I| after every factorisation; prefer Householder.

Link forward: least squares is a projection of the targets onto the span of the features.
