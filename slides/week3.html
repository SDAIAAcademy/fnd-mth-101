Block A · span

The span of some vectors is everything you can build from them

  • A combination of u and v is a u + b v, for any numbers a and b
  • The span is the set of all combinations: a line, a plane, or more
  • (1, 2) and (2, 4) span only a line: the second is twice the first
  • (1, 0) and (0, 1) span the whole plane
For data. The columns of a feature table span the set of predictions any linear model on them can make.

Draw both cases. Ask: can a linear model on (1, 2) and (2, 4) as features predict anything a model on (1, 2) alone cannot? No: the second adds no direction.

Independence

Vectors are independent when none is a combination of the others

Independent

The only combination that gives zero is all coefficients zero. Each vector adds a new direction.

Dependent

Some combination with non-zero coefficients gives zero: 2(1, 2) − (2, 4) = (0, 0). One vector repeats the others.

A basis of a span is an independent set that spans it. Every basis of the same span has the same size: that size is the dimension.

The test: put the vectors in columns and look for a non-zero solution of M c = 0. That set of solutions is the null space; it comes back in the lab's stretch.

Block B · linear systems

Solving A x = b asks which combination of A's columns makes b

One solution

b is in the span and the columns are independent.

Infinitely many

b is in the span and the columns are dependent: one solution plus any null-space vector.

None

b is outside the span. Week 5 finds the closest combination instead.

Read the column picture slowly: x holds the coefficients of a combination. The third case is the normal one in data fitting, with more rows than columns.

Elimination

Elimination subtracts rows until the system is a staircase

StepRows of [A | b]
Start[2, 1, 1 | 4], [4, 3, 3 | 10], [8, 7, 9 | 24]
Row 2 − 2 × row 1; row 3 − 4 × row 1[2, 1, 1 | 4], [0, 1, 1 | 2], [0, 3, 5 | 8]
Row 3 − 3 × row 2[2, 1, 1 | 4], [0, 1, 1 | 2], [0, 0, 2 | 2]

Back substitution from the bottom: z = 1, then y = 1, then x = 1.

From slide_numbers.py, week 3. Do it live, a row at a time, and let the room call out the multipliers. Each step costs about 2n² operations per column: about (2/3)n³ in total for an n × n system.

Pivots

A zero or tiny pivot breaks elimination; swapping rows fixes most cases

  • The pivot is the number you divide by at each step
  • A zero pivot with nothing to swap in means a dependent column: the matrix is singular
  • A tiny pivot magnifies rounding; partial pivoting swaps in the row with the largest entry
  • The number of non-zero pivots is the rank

The lab's elimination uses partial pivoting. Library solvers do the same, with an LU factorisation underneath.

Checkpoint

What does a zero pivot tell you?

Elimination on a 4 × 4 matrix finds no non-zero pivot in the third column, even after looking for a row to swap. What follows?

The computation needs more precision
The system has exactly one solution, found by skipping the column
The columns are dependent; the system has no solution or infinitely many
The right-hand side b must be zero
Why. A missing pivot means a column is a combination of earlier ones: rank below 4, a singular matrix.

Answer C. Which of the two cases depends on b: whether b lies in the span of the columns.

Block C · the inverse

The inverse undoes a map, and exists only when nothing was lost

[[4, 7], [2, 6]] has determinant 4 × 6 − 7 × 2 = 10, so

inverse = [[0.6, −0.7], [−0.2, 0.4]]

Check: multiply them and get the identity.

No inverse

A singular matrix squashes some direction to zero. Nothing can bring it back: two inputs give the same output.

From slide_numbers.py, week 3. The 2 × 2 formula is on the problem set; larger inverses are computed by elimination, never by a formula.

In code

To solve a system, call a solver; do not invert and multiply

x = np.linalg.solve(A, b)      # yes
x = np.linalg.inv(A) @ b       # avoid
  • Solving does less work than inverting
  • It rounds less, and the gap grows with the condition number
  • You rarely need the inverse itself

The lab measures both on a system with condition number 10¹⁰. Be ready for modest differences on a laptop: the point is that solving is never worse.

Rounding

On a computer, "zero" means "small compared with rounding"

  • A float64 number holds about 16 significant digits
  • Exact dependence shows as a singular value of rounding size, about 10⁻¹⁶ times the largest or less, not always exactly 0
  • np.linalg.matrix_rank counts singular values above a tolerance set from the matrix's size and largest value
Near, not exact. A column that almost repeats another keeps the rank full and still makes a solve unstable. Weeks 4 and 5 measure that.

Floating-point limits are taught in full in week 8; here only what the rank needs. Source: the NumPy documentation of matrix_rank.

Checkpoint

Can this table be inverted?

A 3 × 3 matrix has rows (1, 2, 3), (0, 1, 4) and (1, 3, 7). Does it have an inverse?

Yes: no row is all zeros
Yes: no two rows are equal
It depends on the vector b it is used with
No: the third row is the sum of the first two
Why. (1, 2, 3) + (0, 1, 4) = (1, 3, 7). Rank 2: the map squashes a direction, so it cannot be undone.

Answer D. Ask the room to confirm with elimination: the third pivot vanishes.

Week 3 · wrap-up

Three things to keep

Rank counts directions

Columns that repeat others add no information, and a model cannot separate their effects.

Solutions depend on the span

One, none or infinitely many: decided by rank and by whether b is reachable.

Solve, do not invert

Call a solver. The inverse is a concept more than a step.

Ask for one feature pair from their own work that would make a table rank-deficient.
